# Personal Portfolio

My personal website where I share my projects, education, and experience in software development.

**Website:** [magnuslow.com](https://magnuslow.com/)

## Features

- Overview of my projects and experience
- English and Norwegian language support
- Light and dark mode
- Responsive design for desktop and mobile
- Contact form

## Technologies

HTML, CSS, JavaScript, Formspree

## Run locally

Clone the repository and open the project folder.

Start a local server:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

No build tools or additional dependencies are required.

## Deployment

The website is hosted on Vercel as a static site.
